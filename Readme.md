## 🌟 Trang Web Portfolio Cá Nhân (Next.js 15 App Router)

Dự án này là trang web **Portfolio Cá Nhân** thế hệ mới của Giang Thanh Tùng được thiết kế với phong cách **Space / Galaxy & Cyber-Minimalism**, ứng dụng kính mờ **Glassmorphism**, bầu trời sao tương tác **react-tsparticles** và các hiệu ứng chuyển động Zero Gravity mượt mà bằng **Framer Motion**.

### 🛠 Tech Stack Của Web Portfolio:
- **Framework:** Next.js (App Router, React 19, TypeScript).
- **Styling:** Tailwind CSS + Custom Cyber & Glassmorphism design tokens.
- **Animation:** `framer-motion` (hiệu ứng lơ lửng, hover 3D card glow) + `@tsparticles/react` & `@tsparticles/slim` (interactive starry night background opacity 0.25).
- **Icons:** Lucide React.

### 🚀 Huớng Dẫn Chạy Dự Án Lần Đầu:
```bash
# 1. Cài đặt thư viện dependencies
npm install

# 2. Chạy Server phát triển (Development Mode)
npm run dev

# 3. Build sản phẩm cho Production
npm run build
npm run start
```

## 📐 Phân Tích Kiến Trúc & Ứng Dụng Kỹ Năng Thực Chiến

### 1. Cloud-Native Flashcard (VocabFlow) - [19 Cloud-Native Services Architecture]
Dự án ứng dụng tối đa mô hình **Serverless** và **Edge Computing** để chịu tải lớn với chi phí vận hành $0:
- **Edge & Frontend:** `Cloudflare Pages` hosting Next.js tại các cụm Edge toàn cầu (tối ưu TTFB). `Cloudflare Workers` & `Turnstile` định tuyến và chống DDoS. Media lưu trữ qua `Cloudflare R2` (Zero Egress Fee).
- **Compute:** Backend đóng gói `Docker` và thực thi trên `GCP Cloud Run` (tự động Auto-scale và Scale-to-zero). Image quản lý bảo mật qua `Artifact Registry`.
- **Database & Cache:** `Supabase (PostgreSQL)` & `Auth` xử lý dữ liệu và phân quyền JWT. `Upstash Redis` cache từ vựng và `Upstash Rate Limiter` chống Spam API.
- **Async & Automation:** Hệ thống gửi email bất đồng bộ điều phối qua `GCP Cloud Tasks`, `GCP Cloud Scheduler` và `Resend API`.
- **Security & AI:** Lưu trữ key bảo mật bằng `GCP Secret Manager`, phân quyền IAM. Tích hợp `OpenAI API (GPT-4o mini)` tự động dịch và sinh câu ví dụ ngữ cảnh.
- **CI/CD:** Giám sát lỗi realtime với `Sentry`, tự động hóa deploy toàn bộ hạ tầng bằng `GitHub Actions`.

### 2. E-learning DRM (Digital Rights Management)
- **Thiết kế Frontend:** Ứng dụng `Next.js` (App Router) xây dựng trang quản trị ERP phức tạp. Tận dụng Server-Side Rendering (SSR) để tối ưu hóa SEO cho các trang public và Client-Side Rendering (CSR) cho các dashboard quản trị cần tương tác mượt mà.
- **Kiến trúc Microservices (Đa ngôn ngữ):** Hệ thống phân tách rõ ràng trách nhiệm. `.NET Core` đóng vai trò là Core Backend vững chắc, xử lý phân quyền và luồng nghiệp vụ kinh doanh. 
- **Tích hợp xử lý Media & AI:** Một microservice độc lập viết bằng `Python` được gọi để thực hiện các tác vụ tính toán nặng như chèn Watermark động vào video và sử dụng công nghệ thị giác máy tính để nhận diện khuôn mặt (FaceID) người học chống gian lận.

### 3. Code Dream Exam Platform
- **Xử lý tính đồng thời (Concurrency):** Hệ thống thi trực tuyến đòi hỏi giải quyết bài toán "Spike traffic" (lượng truy cập tăng vọt khi nhiều thí sinh cùng vào thi). Sử dụng `FastAPI` giúp xử lý đồng thời hàng ngàn request nộp bài.
- **Tự động hóa giáo dục:** Thiết kế thuật toán thông minh ở backend giúp hệ thống tự động bốc tách, xáo trộn câu hỏi để tạo Ma trận đề thi động và tính năng tự động chấm điểm ngay khi nộp bài. Frontend dùng `React` để quản lý state phức tạp của bài thi thời gian thực.
